# 控制模板资产

本目录中的两张 PNG 由刘小刘制作，用于控制证书生成时的装饰密度、留白和区域秩序：

- `landscape_v3.png`：A4 横版，3508 × 2480 px
- `portrait_v3.png`：A4 竖版，2480 × 3508 px

当前文件名使用 `v3`，表示它们与 V3 标题规则配套：上方中部允许生成唯一主标题，其余变量文字仍后期叠加。

使用时必须把它们当作隐藏的软性参考：

- 只解释装饰密度、留白、标题定位与安静区；
- 不复制灰阶、纹理、轮廓、曲线或形状；
- 不把控制图合成或显示在最终证书中。

作者、许可证、SHA-256 和语义版本见 `asset_manifest.json`。历史 v2 使用说明保存在 `source-v2-usage.md`，其中“不得生成任何文字”的旧规则已被 V3 标题规则取代。
