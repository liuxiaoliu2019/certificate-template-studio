# Security policy

## Supported version

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or Security Advisory feature for this repository. Do not publish credentials, personal paths, private source images, or a working exploit in a public Issue.

Include:

- the affected version;
- the relevant file or workflow stage;
- reproduction steps using non-sensitive fixtures;
- the impact;
- a suggested mitigation, if available.

You should receive an acknowledgement through GitHub after the report is reviewed. No response-time or disclosure-date guarantee is made.

## Scope

Reports about path traversal, unsafe overwrites, credential exposure, untrusted image handling, manifest corruption, or approval-gate bypasses are in scope. Generated-image quality disagreements without a security impact should use a normal Issue.
