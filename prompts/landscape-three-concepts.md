# 横版三方案 Prompt

## 输入

- Image A：教材封面 `{cover_path}`
- Image B：项目内横版隐藏控制图 `{project_dir}/controls/landscape_v3.png`
- Style DNA：`{style_dna}`
- 角色身份档案：`{character_identity}`
- 本方案使用的角色裁切：`{character_reference_paths}`
- 本方案 Style Profile：`{style_profile}`
- 用户手动标题：`{certificate_title}`
- 当前方向：`{concept_name}`
- 当前方向策略：`{concept_strategy}`
- 与另外两方向的差异维度：`{differentiators}`

## 使用方式

先完成 7 个风格家族评分并建立三个不同 Style Profile。确认三个家族不同、分数均不低于 70，且任意两套至少三个核心参数不同后，对每个方向各调用一次以下生成 Prompt。

## 生成 Prompt

参考 Image A 和 Style DNA 的核心元素、配色与气质，并按照本方案 Style Profile 的风格家族、设计角色、边框结构和参数，生成一张 A4 横版证书背景图（3508 × 2480 px，300 DPI 版式感）。这是证书设计，不是教材封面横向改版，也不是活动海报。

若本方案使用角色，同时参考对应原图裁切和角色身份档案。允许改变姿势、动作、朝向和插画媒介；不得改变发型/头部、脸型和五官、肤色或毛羽色、身体比例、服装款式与分区配色、物种或标志性配件。不得混合角色或用通用角色替代。风格可以变化，身份不能变化。

本方案采用“{concept_name}”方向：{concept_strategy}。它与另外两套方案在以下维度上必须明显不同：{differentiators}。

Image B 是主要的隐藏软性区域控制，应遵循它的实际灰阶分布：Z80 边角主装饰、Z50 侧缘次装饰、Z20 柔和过渡、Z12 右下偏内侧签名/日期/盖章功能区、Z08 中央正文安全区。Prompt 不得另行创造与 Image B 冲突的大块空白。不要复制 Image B 的灰阶、纹理、边界、轮廓或形状，也不要让控制图出现在成品中。

若 `concept_role=frame_led`，必须把 `frame_structure=full_frame` 实现为四边连续的证书边框：沿 Z50 侧缘连续，在 Z80 角部增强，使用 Profile 指定的 `frame_language`。教材只提供少量配色、年龄感、气质或主题符号，可以完全不使用角色。完整边框不是标题容器，不得照搬任何参考证书的具体纹样。

中央保持暖白或与风格协调的浅色安全区，只允许极轻微渐变、纹理或气氛，不放主体。右下偏内侧落款功能区保持低对比且实际可排版。左右下角都保留清晰可见的视觉锚点，并以由大到小的同风格图案、线条、环境或色彩形成弱连接。中部可以稀疏但不能生硬断裂；低密度不等于零密度，任何一侧不得完全失重。

在上方横版标题核心区（x 29%–71%，y 12%–21%）准确生成唯一标题“{certificate_title}”。把完整标题外接框的几何中心严格锁定在画布水平中轴 x=50%，不得因人物、装饰或视觉重心向左或向右漂移。标题清晰、完整、大小克制，并与画面风格融合。标题区不得出现横幅、丝带、卡片、底板、徽章、奖牌、描边框或封闭文字容器。

除“{certificate_title}”外，禁止生成任何其他可读或疑似文字，包括姓名、正文、日期、学校、签名、印章、副标题、英文装饰字、教材文字、Logo、出版社与版次信息。

输出完整横版成品，不叠加后期变量信息。
