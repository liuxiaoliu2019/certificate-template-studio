# 封面分析 Prompt

## 输入

- 教材封面：`{cover_path}`
- 输出 schema：`schemas/style_dna.schema.json`

## Prompt

分析这张教材封面，输出可用于“重新设计成证书”的 Style DNA JSON。此阶段只分析，不生成证书图片，也不推荐证书标题。

提取优先级严格为：画风 > 核心元素 > 色彩 > 整体气质 > 原构图。

请完成：

1. 描述插画媒介、线条与形状、渲染方式和细节密度。
2. 提取可重新组合的核心角色、物件、场景和氛围元素，并区分 primary / secondary / atmospheric。
3. 提取主色、辅色、强调色与背景色，给出近似 HEX，仅用于设计沟通。
4. 提取年龄感、正式度、情绪和学科氛围。
5. 只记录原构图中可借鉴的节奏，不建议照搬封面构图。
6. 明确列出不得复制的教材标题、Logo、出版社信息、系列名、级别/版次、ISBN、宣传语与独特文字排版。
7. 给出证书化转换建议：外围承载什么，中心如何退让，右下如何保持安静。
8. 判断封面媒介类型、受众年龄阶段与主题类别。摄影、写实或混合媒介允许提出插画化转译，但必须列出需要保留的核心识别。

此处不要把可识别角色泛化成“通用男孩/女孩/动物”，也不要建议重新设计角色。Style DNA 只记录角色在画面中的主题作用；角色的发型、脸部、服装、毛羽色和配件等身份细节由下一步 `prompts/analyze-character-identity.md` 独立记录。

只返回符合 schema 的 JSON。不要把看不清的品牌文字猜成事实；不确定内容用概括性描述放入 notes。
