# TemplateBidirectional 示例

这是一个不含参考图片和成品图片的纯文本示例，用于展示“横版模板输入 → 先批准横版 → 再生成竖版”的状态。

- 源模板尺寸为 1600 × 1133，因此自动识别为横版。
- `template_dna.json` 只描述设计结构和待删除文字区域，不保存或转录源模板文字。
- manifest 停在 `source_approved`：横版已批准，竖版已解除阻塞并处于 `ready`。
- 示例中的 `*-not-included.*` 路径是版权安全占位符，不包含源模板或成品图片。

若源模板为竖版，流程完全对称：先批准竖版，再生成和批准横版。
