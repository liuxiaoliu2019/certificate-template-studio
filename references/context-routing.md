# 最小阶段上下文

每次只为当前动作建立 `configs/active_context.json`，其中仅列出资源路径、类型和文本字符数，不复制完整文档、历史对话、Prompt 或图片内容。

七种上下文包：分析、规划、横版、局部修改、竖版、多标题、审批。使用 `scripts/context_router.py` 检查阶段白名单、模式隔离、角色实际使用情况和文本预算。

局部修改只携带当前图片、用户当前反馈、活动 Style Profile、标题布局计划、实际使用角色裁切和锁定项。教材模式不加载 Template DNA；模板双向模式不加载 Style DNA 或角色资料。缓存命中时不要把已完成阶段资料重新装入上下文。
