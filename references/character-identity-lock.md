# 人物与动物角色身份锁

封面含可识别人类或动物角色时，在 Style DNA 之后、询问标题之前读取。目标是允许姿势和插画媒介变化，同时保持角色身份稳定。

## 1. 建立身份档案

输出 `analysis/character_identity.json`，符合 `schemas/character_identity.schema.json`。为每个可识别角色记录：

- `character_id` 与 `category`；
- 原封面归一化区域 `source_region`；
- 头部/发型、脸部、肤色或毛羽色、身体比例；
- 服装款式与分区配色、标志性配件；
- 动物的物种、耳角羽冠、斑纹和尾部等识别特征；
- `immutable_traits`、`allowed_transformations`、`forbidden_changes`；
- 由原封面直接裁切的 `reference_crop` 路径。

只记录真正看得见的特征。遮挡、模糊或封面外的部分标为不可验证，不得猜测补全。

## 2. 裁切参考

身份 JSON 完成后运行：

```text
python scripts/extract_character_refs.py <项目目录> --registry analysis/character_identity.json
```

裁切只隔离原图区域，不重绘、不改色、不去除原有角色细节。裁切结果保存到 `analysis/character_refs/`。完整封面仍需作为生成参考；裁切不能代替完整封面。

## 3. 生成输入顺序

含角色方案按以下顺序提供图像参考：

1. 完整教材封面；
2. 本次实际使用角色的全部原图裁切；
3. 对应横版或竖版隐藏控制图；
4. 修改任务另加当前成品或已批准 Master。

Prompt 同时提供对应角色档案，并明确“风格变、身份不变”。未使用的角色无需放入本次裁切输入。

## 4. 允许变化

- 姿势、动作、手势、视线方向和边缘探入方式；
- 横竖版中的位置、尺寸和朝向；
- 扁平、水彩、手绘、纸艺、线描等表现媒介；
- 不改变身份的表情幅度和场景互动。

## 5. 不可改变

- 人类：发型、发色、脸型、五官结构、肤色、年龄感、身体比例、服装主款式与分区配色、鞋帽和标志性配件。
- 动物：物种、头部结构、耳角羽冠、毛羽色、斑纹、身体比例、尾部和标志性配件。
- 所有角色：不得混合两名角色的特征，不得无依据新增身份，不得用通用替代角色顶替原角色。

若一个方案难以同时保持多个角色，减少角色数量，不降低身份要求。

## 6. 独立身份验收

含角色成品先评分，满分 100：

| 维度 | 分值 |
|---|---:|
| 头部、脸部或动物头部特征 | 30 |
| 发型、头饰、耳角羽冠等轮廓 | 20 |
| 服装、肤色、毛羽色与分区配色 | 20 |
| 身体比例、物种和年龄感 | 15 |
| 标志性配件 | 10 |
| 无混角、无无依据新增特征 | 5 |

低于 85 分，或任一不可改变项明显错误，即 `identity_hard_fail=true`。先进行针对性修正，连续最多两次。仍失败时可提交另一套不含该角色且合格的方案，并说明角色版本未通过；不得把失败图交给用户选择。

不含角色的方案记录 `identity_check=not_applicable`，不加分也不扣分。
