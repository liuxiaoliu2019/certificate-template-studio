# 设计规则

## 1. 四层职责分工

- 教材 Style DNA 决定“画什么”：核心元素、色彩关系、气质和可转译的媒介特征。
- 证书 Style Profile 决定“用什么证书语言表现”：边框、材质、典礼感、插画组织和角色使用。
- Style Profile 的有限参数控制同一风格家族内的变化，不能自由混搭成风格拼盘。
- 隐藏控制图决定“哪里多画、哪里少画”：区域秩序、装饰强弱、正文和落款留白。
- 用户决定唯一主标题与最终审美选择。
- Codex 负责流程、状态、提示词和资产历史。

控制图仅作为生成参考，不进入成品。禁止复制其灰阶、纹理、轮廓、曲线或几何形状。

## 2. Style DNA 提取优先级

顺序固定：

1. 画风：媒介感、线条、明暗、材质、角色造型、细节密度。
2. 核心元素：能够让人联想到教材主题、但可重新组合的角色、物件、场景和符号。
3. 色彩：主色、辅色、强调色、明度与饱和度关系。
4. 整体气质：年龄感、正式度、活力、温度、学科氛围。
5. 原构图：只提取可用的节奏或重心线索，优先级最低，不直接照搬。

Style DNA 必须同时记录 `avoid_copying`：教材标题、出版社/系列 Logo、版次、ISBN、宣传语、独特文字排版和不必要的品牌标识。

## 3. 证书化原则

- 目标是“同一视觉语言的证书”，不是“把教材封面改成横版”。
- 中央正文安全区必须可供后期排版，允许弱渐变或极浅纹理，但不能有主体元素、强对比图案或伪文字。
- 右下偏内侧约 20%–25% 宽 × 20% 高是落款功能区，供日期、学校、签名和印章使用；其中不放人物、动物、建筑、大花丛或强对比主体。
- 落款功能区不等于右下整个物理角落归零。最外侧右边缘、底边缘和物理角仍应遵循控制图的灰阶分布，以低至中等密度的小型装饰、连续色彩、渐变或气氛形成视觉收口。
- 禁止把“安静”解释成孤立的矩形白洞。边缘装饰应自然减弱而不是突然截断；在尚未叠加变量文字时，背景本身也应保持构图完整。
- 主要视觉退到边缘、角部或侧缘，向中心自然减弱。
- 画面要有证书感与完成度，避免活动海报式大 KV、过密角色群或宣传页式信息层级。

## 4. 三方案差异

三个方向必须来自三个不同且兼容性达到 70 分的风格家族。任意两套至少在下列三个维度上实质不同：

- 主视觉组织方式
- 边缘与角部装饰结构
- 角色/IP 的数量、位置或露出方式
- 标题的视觉处理
- 视觉重心与动势
- 边框或无边框语言
- 留白轮廓与装饰向中心的过渡方式

只换配色、装饰小物、标题字体或同构图的细微位置不算不同方向。方向名称应由 Style DNA、风格家族和 Profile 策略共同决定。

## 5. 版权与内容边界

- 可以提取一般性的视觉特征与主题元素，但不得复刻教材封面构图或复制其中的可读文字、Logo、出版社标识和独特商业版式。
- 不要把教材封面嵌入成品，不要生成看似官方联名或出版社授权的标识。
- 示例、测试配置和日志只写抽象描述；除非用户明确提供并允许保存，Skill 包内不放教材封面。

## 6. 交付前硬性检查

- 只有一个可读标题，且逐字正确。
- 无姓名、正文、日期、学校、教师、签名、印章、副标题、英文装饰字或伪文字。
- 正文安全区无主体侵入。
- 右下偏内侧落款区可实际排版，最外沿仍有克制的视觉收边。
- 右下没有与其他外围失联的大块纯空白，整体视觉重量不过度偏向左下。
- 左右下角都有清晰可见的视觉锚点；两侧通过由大到小的同风格元素形成弱连接，任何一侧不能完全失重。
- 控制图没有以灰阶、纹理或轮廓形式出现在成品。
- 看得出教材的视觉语言，但不是封面的复制品。
