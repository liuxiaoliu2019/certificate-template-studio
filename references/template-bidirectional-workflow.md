# 证书模板双向生成

用户提供现成横版或竖版证书/奖状模板，并要求输出横竖两个版本时读取。源模板是设计权威；该模式不需要教材封面、教材 Style DNA 或横版三方案。

## 1. 方向与顺序

- `width > height`：源方向为 `landscape`，先重制横版并批准，再衍生竖版。
- `height > width`：源方向为 `portrait`，先重制竖版并批准，再衍生横版。
- 正方形或尺寸无法判断：暂停并请用户指定 `landscape` 或 `portrait`。
- 用户源模板记录为 `source_locked`；这只锁定设计依据，不授权保留源文字。

## 2. 文字处理

- 源模板中的标题、副标题、正文、姓名、日期、学校、签名、印章文字、Logo 和水印文字全部删除。
- Template DNA 只保存文字区域类别、归一化坐标和 `remove` 动作，不保存或转录原文。
- 分析后只询问用户手动输入一个证书标题；已提供时不重复询问。
- 横竖版唯一可读文字都是该标题，其余变量信息留给后期叠加。

## 3. 高保真设计锁

必须保持：主辅色比例，外框/主装饰框/内框层级，纹样造型语言与重复节奏，线条粗细关系，材质，角部强化，对称方式，正式度和非文字装饰身份。

允许变化：为目标方向重新计算四边长度、重复次数、纹样间距、角花尺度和非文字装饰位置；标题字号、字距和换行可按方向适配。

禁止：旋转、拉伸、横向或纵向压缩、机械裁切、只取中间区域、直接扩边、复制横版/竖版布局、明显重复接缝、擅自换色或替换边框家族。

模板含可识别人类或动物角色时，复用 `references/character-identity-lock.md`；角色可以换姿势和位置，但身份不可漂移。

## 4. 同方向重制

同方向版本不是简单擦字。用源模板、Template DNA、同方向控制图和用户标题重新生成完整模板：清除文字及其背景痕迹，恢复正文/姓名/落款安全区，只生成唯一标题，并保持设计身份。

评分达标后暂停。用户必须明确包含“横版定稿”或“竖版定稿”的批准原话；源方向未批准时，另一方向状态保持 `blocked`。

## 5. 另一方向衍生

同时输入源模板、Template DNA、已批准同方向 Master、目标控制图和用户标题。按目标方向重新构图，保持同一设计系统但改变纵横节奏。不得以旋转、拉伸、裁切或扩边代替设计。

- 横版标题：外接框中心 x=50%，使用横版 V3 标题核心区。
- 竖版标题：外接框中心 x=50%，相对原 V3 基准向上 1.5 cm。

## 6. 评分与硬失败

| 维度 | 分值 |
|---|---:|
| 源模板设计身份保留 | 30 |
| 当前方向重构质量 | 25 |
| 标题准确、居中及竖版上移 | 15 |
| 中央与落款功能区 | 15 |
| 原文字清除与无多余文字 | 10 |
| 无拉伸、裁切和重复破绽 | 5 |

85–100 分且无硬失败才可提交；75–84 分先自动修正；低于 75 分不提交。每个方向连续自动修正最多两次。

硬失败：文字残留或伪文字、标题错误/偏位、竖版标题未上移、边框断裂、压缩/拉伸/裁切、纹样严重变形或接缝、配色/材质/典礼感丢失、功能区被侵占、控制图进入成品、角色身份失败。

## 7. 状态、修订与 Master

```text
initialized -> template_analyzed -> waiting_for_title -> title_confirmed
            -> regenerating_source -> awaiting_source_approval -> source_approved
            -> deriving_opposite -> awaiting_opposite_approval -> complete
```

- 初始化：`scripts/init_template_project.py`
- 标题、阶段、选择和审批：`scripts/update_template_manifest.py`
- 修改与回退：`scripts/record_template_revision.py`

源方向批准后若发生实质修改，目标方向若已生成则标为 `stale`。两个方向分别批准后保存双 Master。同模板后续新标题默认同时复用横竖 Master，只调整标题排版。
