# 智能启动与恢复规则

## 新项目

- 用户只说“使用 Skill 开始工作”或没有明确图片用途时，原样显示两项模式菜单。
- 用户明确说“模式 1”“教材封面生成证书”等表达时，直接锁定 `textbook_cover`，不重复菜单。
- 用户明确说“模式 2”“现成模板双向转换”等表达时，直接锁定 `template_bidirectional`，不重复菜单。
- 一句话同时包含模式、图片和标题时一次接收，缺什么只问什么。
- 同时匹配两个模式、表达互相冲突或无法判断时显示菜单，不猜测。

## 已有项目

- 定位到已有 manifest 时，以 manifest 中的 `selected_mode` 和 `workflow.stage` 恢复。
- 用户说“继续”时从下一项未完成动作开始，不重新显示菜单、不重新询问标题、不重复有效分析。
- manifest 缺少有效模式或阶段时停止，并说明项目需要迁移或修复。

## 模式边界

- 模式切换必须建立新项目。
- 教材模式不得复用模板模式的 Template DNA。
- 模板模式不得伪造教材 Style DNA 或三方案探索记录。
