# 风格兼容性评分

在 Style DNA 和用户标题均已获得后、生成三套横版前读取。

## 评分表

| 维度 | 权重 | 证据来源 |
|---|---:|---|
| 画风兼容性 | 35 | 媒介、线条、形状、渲染和细节密度 |
| 核心元素适应性 | 25 | 人物、动物、建筑、自然或学科元素如何证书化 |
| 色彩兼容性 | 20 | 主辅色能否进入该风格而不失真 |
| 整体气质兼容性 | 15 | 年龄感、正式度、活力、温度和学科氛围 |
| 原构图可转化性 | 5 | 节奏与重心能否转移到证书外围 |

每项按自身上限给整数分，并提供一条基于 Style DNA 的理由。总分是五项之和，权重顺序不得调整。

## 合格线与适配

- 原始配置总分达到 70 才能进入候选。
- 若不足三个家族达到 70，可对相邻家族进行受控适配，例如降低典礼感、把摄影转成线稿或提取教材色彩替换默认色。
- 适配后必须重新评分；仍低于 70 不得进入候选。
- 不得为了凑够三个候选虚报分数或忽略明显年龄、气质冲突。

## 选择三个候选

1. 先按总分排序。
2. 选择三个不同的 `style_family`，并依次分配 `cover_character_led`、`balanced_translation`、`frame_led`。
3. 为每个候选生成一份完整 Style Profile。
4. 任意两份 Profile 至少有三个核心参数不同。
5. 若缩略图预期仍像同一模板换色，重配参数后再生图。

`frame_led` 的教材兼容不按“用了多少封面人物或场景”判断。它可以不使用角色，核心元素适应性主要检查：教材主色或强调色、年龄感、课程气质和少量主题符号能否自然进入完整证书边框。第三个候选不得因 `textbook_fusion=conservative` 被机械降分；但风格家族总分仍须达到 70。

默认第 3 个 Profile 必须同时满足：`concept_role=frame_led`、`frame_structure=full_frame`、`textbook_fusion=conservative`。前两个 Profile 不得都使用 `full_frame`，以保持结构差异。

标题长度只影响标题排版参数，不改变风格兼容性得分。
