# V3 标题与隐藏控制规则

## 1. V3 的含义

V3 继续使用原 v2 灰阶装饰密度结构，并提供标题定位区。标题可以由生成模型融合，也可以在收尾阶段确定性绘制；控制图片本身没有可见标题框，也不应出现在最终证书中。

## 2. 灰阶语义

| 语义 | 强度 | 用途 |
|---|---:|---|
| Z80 | 80 | 边角主装饰与主题视觉许可区 |
| Z50 | 50 | 侧缘次装饰与辅助图形区 |
| Z20 | 20 | 装饰向正文区的柔和过渡 |
| Z12 | 12 | 签名、日期、学校与盖章安静区 |
| Z08 | 8 | 正文核心安全区，仅允许极弱气氛 |

这是软约束而非像素蒙版。目标是守住秩序，同时允许自然的插画过渡。

### 右下区域的解释优先级

- 项目内对应方向的控制图是区域密度的主要依据；Prompt 只能解释控制图，不能覆盖其实际灰阶分布。
- Z12 指右下偏内侧的落款功能区，不代表右下整个物理角落必须空白。
- 右下最外侧边缘和物理角若在控制图中属于 Z20、Z50 或 Z80，应保留相应但克制的装饰或气氛，使外围闭合；不得复制控制图形状。
- 禁用 `almost empty`、`nearly empty`、`strictly blank` 或“右下整块留白”等容易产生白洞的表述。改用“内侧可排版、外沿视觉连续、低密度但不归零”。

## 3. 标题坐标

坐标为相对画布百分比，原点在左上。

### 水平中轴硬锁

- 横版和竖版都必须把“完整标题外接框的几何中心”锁定在画布水平中轴 `x = 50%`。
- 居中指标题整体外接框居中，不是某个字、某一行、标题容器或周围装饰居中。允许字形本身有极小的视觉出挑，但不得以人物、装饰、字数或画面重心为由把标题整体向左或向右偏移。
- 生成后应检查标题左右边界：`(left_x + right_x) / 2 ≈ 50%`。明显偏离中轴即视为失败并优先局部重试。

### 横版

- 外层允许区：x 23%–77%，y 9%–24%
- 文字核心区：x 29%–71%，y 12%–21%
- 标题外接框中心：x 50%；横版垂直位置沿用上述 V3 范围。

### 竖版

- 原 V3 基准：外层允许区 x 17%–83%、y 10%–26%；文字核心区 x 24%–76%、y 14%–23%。
- 当前固定规则：在原基准上整体向上移动 `1.5 cm`，按画布高度 `5.05%` 执行；正式竖版 2172 px 高约为 110 px。
- 上移后的外层允许区：x 17%–83%，y 5%–21%。
- 上移后的文字核心区：x 24%–76%，y 9%–18%。
- 标题外接框中心：x 50%；垂直中心建议约 y 13.5%。

标题整体以 x 50% 为硬中心落在对应核心区。两端可用极淡雾化或小型陪衬装饰形成视觉收口，但陪衬装饰不得被误当成标题宽度，也不得压入正文区。

## 4. 标题视觉

- 标题必须完整、清晰，并以标题外接框中心严格对齐画布 x 50% 中轴；同时与教材画风、色彩和装饰语言融合。
- 标题不能大到像海报主 KV，需与正文留白保持呼吸感。
- 主标题可按标题设计计划使用浅弧、单/双层丝带或插画融合底座；容器只能服务唯一主标题，不能承载姓名、正文、日期、签名等变量信息。
- 禁止额外的姓名卡、正文卡、日期徽章、签名横幅或第二文字容器。
- 可有少量非文字装饰，但不能降低字形识别度。

## 5. 唯一文字规则

允许生成：用户手动输入的一个证书主标题。

禁止生成：姓名、奖励正文、班级、学校、教师、日期、签名、印章文字、副标题、英文装饰字、口号、教材原文、Logo 字样以及任何其他可读或疑似文字。

姓名、正文、日期、学校、签名、印章等变量信息必须后期叠加。

## 6. 标题模式

标题自动选择 `vector_flat`、`vector_effect` 或 `ai_integrated`。详细选择、颜色和收尾规则见 [output-and-title-rendering.md](output-and-title-rendering.md)。前两种模式的原始生图必须全图无文字，唯一标题在最终像素画布上绘制；只有 `ai_integrated` 在生图阶段直接生成唯一标题。

## 7. 固定控制语义

每个生图 prompt 都应包含等价约束：

> 仅将项目控制图视为装饰密度、留白位置与标题区的隐藏参考，不复制其中的灰阶、纹理、轮廓或形状。遵循其实际灰阶分布：边缘高强度区承载主题装饰并向中心减弱；中央保持干净；右下偏内侧落款区低对比且可排版，右下最外沿继续以克制装饰或气氛形成视觉闭合，不得变成孤立的大块纯空白。标题模式由 `title_treatment` 决定；最终标题外接框中心锁定 x=50%，竖版再按画布高度 5.05% 上移。最终成品除该标题外禁止任何其他可读或疑似文字。

## 8. 错字与重试

- 标题逐字错误、缺字、多字或出现其他文字时，该图不得成为候选或 Master。
- 标题外接框中心明显偏离画布 x 50%，或竖版未执行向上 1.5 cm 的固定偏移时，该图不得成为候选或 Master。
- `ai_integrated` 画面主体合格而标题失败时，优先做标题区域局部编辑，保留其余构图。
- `vector_flat` 或 `vector_effect` 的字体、颜色或效果失败时，只重新执行确定性标题收尾，不重生成底图。
- 模型反复失败时向用户说明限制；不要在未记录修订的情况下擅自切换标题模式。

六种标题家族、`CERTIFICATE OF COMPLETION` 强制语义分行、字体角色和质量门详见 [title-design-system.md](title-design-system.md) 与 [output-and-title-rendering.md](output-and-title-rendering.md)。
